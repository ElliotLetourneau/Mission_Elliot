# Elliot Létourneau — Portfolio

Site portfolio personnel présentant mes projets et créations.  
Accessible en ligne via GitHub Pages.

🔗 **[Voir le site](https://elliotletourneau.github.io/Mission_Elliot/)** 

---

## Structure du projet

```
portfolio/
├── index.html        # Page principale (galerie + bio)
├── css/              # Feuilles de style
├── js/               # Scripts JavaScript
├── images/           # Images des posts
├── posts/            # Pages individuelles de chaque post
└── videos/           # Fichiers vidéo
```

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (vanilla)

## Déploiement

Le site est déployé automatiquement via **GitHub Pages** à chaque push sur la branche `main`.
